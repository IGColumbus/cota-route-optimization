# AGENTS.md

Repository automation and coding agents must read and obey
[`docs/ENGINEERING_RULES.md`](docs/ENGINEERING_RULES.md) before modifying this
project. The frozen-research and provenance rules apply to all work:

* the research record is frozen at commit `cd03af9c` (`research-final`);
* never edit registered closeouts, canonical JSON artifacts or git history to
  make a release cleaner; record errors as errata and framing changes in
  `docs/REPORTING_CORRECTIONS.md`;
* move files rather than delete them, and record every move in
  `docs/research-record/MOVES.md`.
