# outputs/

This folder holds the study's artifacts. Its layout is kept as it was at `research-final` (`cd03af9c`). The frozen registry (`CANONICAL_RESULTS_v5.json`), the freeze manifests (`GEN1_FREEZE_MANIFEST.json`, `exp3/FREEZE_MANIFEST.json`) and the experiment contracts all name artifacts by these paths, so the canonical artifacts were **not** moved into an `outputs/canonical/` folder. Moving them would mean either rewriting frozen manifests or issuing a new registry version; that is a release decision recorded in `docs/RELEASE_PROVENANCE.md`.

* **Canonical (release-facing) artifacts:** listed below from `CANONICAL_RESULTS_v5.json → experiments.*.canonical`. That registry is the authority; v1–v4 are kept unchanged.
* **Superseded artifacts:** moved on 2026-10-05 to `outputs/superseded/` (same sub-paths). `SUPERSEDED.md` is the human-readable index; its paths are as of `research-final`, and `docs/research-record/MOVES.md` gives the new locations.
* **Run logs:** moved on 2026-10-05 to `docs/research-record/run-logs/` (same sub-paths). They are forensic history, not results.
* **Report figures:** `docs/report/figures/`, generated by `scripts/make_report_figures.py`.
